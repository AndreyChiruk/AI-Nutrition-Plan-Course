# AI Nutrition Plan - Интеллектуальный сервис для планирования питания
## О проекте
**AI Nutrition Plan** — это веб-приложение для персонализированного планирования питания с использованием искусственного интеллекта. Сервис помогает пользователям составлять рационы с учётом целей, аллергий, пищевых ограничений и доступных продуктов.
## Основные возможности
### Для пользователей
- Регистрация и авторизация (email + пароль или код на почту)
- Управление профилем (рост, вес, цель, уровень активности)
- Настройка аллергий и пищевых ограничений
- Генерация планов питания (AI + каталог блюд)
- Конструктор рациона с учётом продуктов пользователя
- Распознавание еды по фотографии
- AI-чат для консультаций по питанию
- Отслеживание прогресса и статистика
- Планирование тренировок
- Анализ тела по фото
- Ведение личного списка продуктов ("холодильник")
### Для администраторов
- Панель администратора
- Модерация пользователей (блокировка/разблокировка)
- Модерация сомнительных записей о еде
- Статистика активности платформы
- Импорт рецептов из внешних API (TheMealDB, TheCocktailDB)
## Технологический стек
**Backend:**
- Node.js + NestJS + TypeScript
- PostgreSQL + Sequelize ORM
- OpenAI API (распознавание, рекомендации, чат)
- JWT-аутентификация
**Frontend:**
- React + TypeScript + Vite
- Axios, React Router
- Recharts (графики)

**Инфраструктура:**
- Docker + Docker Compose
- Nginx (reverse-proxy)
