# Отложенные задачи

## Приоритет СНГ-блюд в планировщике

**Статус:** отложено по решению заказчика.

**Проблема.** Курируемые блюда СНГ-кухни составляют 10 % каталога
(72 из 733 опубликованных). Планировщик выбирает блюда случайно из пула
по категории, поэтому в плане на 5 дней из 15 приёмов пищи оказалось
всего 1 знакомое блюдо. Причина не в алгоритме, а в пропорции:
на 19 СНГ-обедов приходится 438 иностранных.

**Варианты решения (обсуждались):**

| Вариант | Суть | Оценка |
|---|---|---|
| A. Вес в планировщике | Знакомым блюдам даётся приоритет, иностранные остаются для разнообразия | ~0.5 ч |
| B. Скрыть иностранные | Пометить `is_published = false` для 658 блюд | 10 мин, но выбор падает до 72 |
| C. Расширить список до ~250 | Добавить ещё ~180 блюд вручную | 6–8 ч |

**Рекомендация:** вариант A + фильтр по кухне в интерфейсе
(«СНГ» / «любая»), чтобы пользователь выбирал сам.

**Где менять:** `src/meal-plan/meal-plan.service.ts` — функция
`productPreferenceScore` уже даёт +8 за любимые продукты; аналогичный
вес можно добавить для кухни.

## Иностранные блюда: качество составов

Часть блюд TheMealDB имеет некорректный состав из-за свободной формы мер
в источнике («1 ½ tbsp», «to taste»): импорт подставлял значение
по умолчанию `DEFAULT_PIECE_GRAMS = 60`. Исправлено 474 блюда, но
18 блюд имеют состав, где больше половины массы — специи и соусы.
10 безнадёжных скрыто (`is_published = false`).

**Что можно сделать:** выборочная ручная проверка оставшихся 18 блюд,
либо улучшение парсера мер в `src/admin/recipe-import.util.ts`.
